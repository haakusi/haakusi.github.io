1. 프로그래밍은 문제를 실행 가능한 형태로 바꾸는 일

프로그래밍은 문법을 외우는 활동에 그치지 않는다. 현실의 문제를 컴퓨터가 처리할 수 있는 데이터와 단계로 바꾸고, 실행 결과를 검증하며, 틀렸을 때 다시 고칠 수 있게 표현하는 작업이다. 인공지능 프로그래밍에서도 모델보다 먼저 문제와 입력·출력·평가 기준을 분명히 해야 한다.

2. 컴퓨팅 사고의 다섯 단계

단계핵심 질문간단한 예
문제 분해큰 문제를 어떤 작은 단위로 나눌까?데이터 입력, 전처리, 계산, 출력, 검증으로 분리
패턴 인식반복되는 구조와 예외는 무엇인가?같은 계산을 배열 전체에 적용
추상화핵심만 남기고 무엇을 숨길까?세부 구현 대신 함수의 입력·출력으로 표현
알고리즘 설계어떤 순서와 조건으로 해결할까?단계, 분기, 반복을 명시
검증·개선예상과 실제가 일치하는가?경계값과 잘못된 입력까지 테스트
문제 → 분해 → 패턴 → 추상화 → 알고리즘 → 실행·검증 → 개선

3. NumPy로 수학을 배열 연산으로 옮기기

NumPy는 숫자 배열을 효율적으로 계산하게 해준다. 반복문으로 원소를 하나씩 처리하기보다 같은 수학 연산을 배열 전체에 적용하는 벡터화가 핵심이다.

함수수학적 의미AI에서 만나는 곳
np.sqrt(x)제곱근 √x거리, 노름, 표준편차 같은 크기 계산
np.exp(x)지수함수 ex확률 변환, 활성화 함수, 손실 계산의 구성요소
import numpy as np

x = np.array([1.0, 4.0, 9.0])
roots = np.sqrt(x)          # [1.0, 2.0, 3.0]

z = np.array([0.0, 1.0])
growth = np.exp(z)          # [1.0, e]
  • 실수 범위에서 음수의 제곱근은 그대로 계산할 수 없으므로 입력 영역을 확인한다.
  • 지수함수는 빠르게 커져 overflow가 날 수 있으므로 수치 안정성을 생각한다.
  • 함수 이름만 외우지 말고 입력의 shape, 출력값, 수학적 의미를 함께 확인한다.

4. 퍼셉트론 하나를 수식으로 이해하기

퍼셉트론은 여러 입력에 각각의 가중치를 곱하고 편향을 더한 뒤 활성화 함수를 통과시킨다.

z = w1x1 + ··· + wnxn + b = w · x + b  ·  y = g(z)
요소역할
입력 x모델이 판단에 사용하는 특징
가중치 w각 입력이 결과에 미치는 방향과 크기
편향 b결정 경계의 기준 위치를 이동
가중합 z입력 증거를 하나의 값으로 모음
활성화 함수 g가중합을 출력 신호로 변환

가중치 몇 개가 어떻게 바뀌는지도 중요하지만, 여러 퍼셉트론이 층을 이루고 데이터가 앞으로 흐르며 오차가 계산되고 가중치가 갱신되는 전체 구조도 함께 봐야 한다.

5. 부분에서 전체 시스템으로

데이터 → 전처리 → 모델의 가중합·활성화 → 예측 → 손실 → 최적화 → 평가 → 피드백

코드 한 줄은 전체 시스템 안에서 역할이 있다. sqrt나 exp도 단독 명령어가 아니라 거리·확률·활성화·손실을 구성하는 수학이다. 미시적으로는 수식과 배열의 값을 추적하고, 거시적으로는 데이터가 결과까지 어떻게 이동하는지 설명해야 한다.

6. 이론과 실습을 연결하는 학습 원칙

  • 이론 먼저: 수식의 변수, 가정, 입력 범위와 예상 출력을 적는다.
  • 작은 실험: 손으로 계산 가능한 배열부터 실행해 예상과 비교한다.
  • 전체 적용: 작은 함수가 모델 파이프라인에서 맡는 역할을 연결한다.
  • 무작위 파라미터 조정 금지: 이유 없이 수치를 바꾸는 대신 가설을 세우고 결과를 해석한다.

7. AI를 활용하되 AI 결과를 그대로 복사하지 않기

AI는 문법 설명, 예제 생성, 오류 후보 탐색, 테스트 아이디어에 유용하다. 그러나 AI 결과를 그대로 복사하면 코드가 실행되어도 왜 동작하는지, 어떤 입력에서 실패하는지 설명하기 어렵다.

  1. 먼저 문제와 예상 결과를 자신의 말로 쓴다.
  2. 작은 코드를 직접 작성하고 실행한다.
  3. 막힌 부분만 AI와 공식 문서로 확인한다.
  4. 응답을 검증한 뒤 자신의 구조로 다시 작성한다.
  5. 코드 없이도 수식·입력·출력·실패 조건을 설명한다.

핵심 인사이트. 인공지능프로그래밍의 목표는 GPU 위에서 숫자를 계속 바꾸는 데 있지 않다. 수학적 구조를 이해하고, 작은 연산이 전체 시스템에서 어떤 역할을 하는지 설명하며, 이론을 검증 가능한 코드로 옮기는 설명 가능한 이해가 먼저다.

1. Programming Turns a Problem into an Executable Form

Programming is more than memorizing syntax. It translates a real problem into data and steps that a computer can execute, makes the result testable, and leaves a path for correction. In AI programming, the problem, inputs, outputs, and evaluation criteria should be clear before the model.

2. Five Moves in Computational Thinking

MoveQuestionExample
DecompositionWhich smaller units make up the problem?Separate input, preprocessing, computation, output, and validation
Pattern recognitionWhat repeats, and what is exceptional?Apply one operation to every array element
AbstractionWhat matters, and what detail can be hidden?Describe a function by its input and output
Algorithm designWhich sequence, branches, and loops solve it?Write explicit steps and conditions
ValidationDoes the actual result match the expectation?Test boundaries and invalid inputs
Problem → decomposition → patterns → abstraction → algorithm → execution and validation → improvement

3. Moving Mathematics into NumPy Arrays

NumPy applies numerical operations efficiently across arrays. Vectorization connects mathematical notation with executable code.

FunctionMeaningWhere it appears in AI
np.sqrt(x)Square root √xDistances, norms, and standard deviations
np.exp(x)Exponential exProbability transforms, activation functions, and loss components
import numpy as np

x = np.array([1.0, 4.0, 9.0])
roots = np.sqrt(x)          # [1.0, 2.0, 3.0]

z = np.array([0.0, 1.0])
growth = np.exp(z)          # [1.0, e]

Check input domains, array shapes, and numerical stability: real square roots do not accept negative inputs directly, while exponentials can overflow rapidly.

4. Understanding One Perceptron

A Perceptron multiplies inputs by weights, adds a bias, and passes the weighted sum through an activation function.

z = w1x1 + ··· + wnxn + b = w · x + b  ·  y = g(z)
PartRole
Input xFeatures used for the decision
Weight wDirection and strength of each feature's influence
Bias bMoves the reference position of the decision boundary
Weighted sum zCombines evidence into one value
Activation function gConverts the sum into an output signal

Individual weights matter, but so does the whole system: perceptrons form layers, data flows forward, error is measured, and optimization updates parameters.

5. From Components to a Complete System

Data → preprocessing → weighted sums and activations → prediction → loss → optimization → evaluation → feedback

A line such as sqrt or exp is not an isolated trick; it implements part of a distance, probability, activation, or loss. Track values locally and explain the end-to-end flow globally.

6. Connect Theory and Practice

  • Theory first: write variables, assumptions, domains, and expected outputs.
  • Small experiment: begin with arrays that can be checked by hand.
  • System connection: locate each function in the model pipeline.
  • No blind tuning: form a hypothesis before changing parameters, then interpret the result.

7. Use AI Assistance without Copying Its Answer

AI can explain syntax, generate examples, suggest error causes, and propose tests. Copying an answer directly, however, leaves the learner unable to explain why the code works or where it fails.

  1. State the problem and expected result in your own words.
  2. Write and run the smallest version yourself.
  3. Use AI and official documentation only for the blocked part.
  4. Verify the response and rewrite it into your own structure.
  5. Explain the equation, input, output, and failure conditions without the code.

Key Insight. AI programming is not blind parameter clicking on a GPU. It begins with the mathematical structure, connects small operations to the whole learning system, and turns theory into code that can be tested and explained.
