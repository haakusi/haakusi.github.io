Week 3 — Data Representation, Numerical Error, and Complex Values

Python values · Binary representation · Domain-aware verification

이번 주는 값이 컴퓨터 안에서 어떻게 표현되고 해석되는지를 살펴본다. 같은 수학적 값이라도 객체·메모리·진법·자료형을 어떻게 선택하느냐에 따라 코드의 동작과 오차가 달라진다. 핵심은 화면에 나온 숫자를 그대로 믿는 것이 아니라 표현 방식, 허용 오차, 경계 조건을 설명하고 검증하는 것이다.

1. 변수·객체·메모리 주소

변수 이름은 메모리 주소 그 자체가 아니다. 파이썬에서 변수는 객체에 바인딩된 이름이고, 실제 메모리 배치와 관리는 인터프리터가 맡는다. 대입은 객체를 복사하지 않고 같은 객체에 이름을 하나 더 연결한다. 얕은 복사는 바깥 컨테이너만 새로 만들고, 깊은 복사는 내부의 중첩 객체까지 재귀적으로 복제한다.

import copy

original = [[1, 2], [3, 4]]
alias = original
shallow = original.copy()
deep = copy.deepcopy(original)

original[0][0] = 99
print(alias[0][0], shallow[0][0], deep[0][0])

출력은 99 99 1이다. 별칭과 얕은 복사는 첫 번째 내부 리스트를 공유하지만 깊은 복사는 공유하지 않는다. 운영체제의 파일 잘라내기·붙여넣기나 편집기의 클립보드 동작은 별도의 규칙을 따르므로, 이를 파이썬 객체 대입과 같은 메모리 모델로 일반화하면 안 된다.

2. 식별자와 고유 식별자

식별자는 코드 안에서 변수·함수·클래스를 가리키는 이름이다. 파이썬 식별자는 숫자로 시작할 수 없고 예약어를 사용할 수 없으며, 읽기 쉬운 snake_case가 보편적이다. 이름 길이를 임의의 64자로 제한하는 규칙은 파이썬 문법의 일반 규칙이 아니다.

개념목적예
프로그램 식별자코드에서 값을 읽기 쉽게 가리킴sensor_temperature
도메인 키업무 규칙 안에서 대상을 구분학번, 주문번호, 장치번호
UUID분산 환경에서 충돌 가능성을 매우 낮춘 식별자128비트 UUID

고유성은 이름을 길게 쓰는 것만으로 보장되지 않는다. 생성 규칙, 유효 범위, 중복 검사, 저장소 제약조건을 함께 설계해야 한다.

3. 10진 정수를 2진수로

양의 10진 정수를 2로 반복해서 나누고 나머지를 아래에서 위로 읽으면 이진 표현을 얻는다. 11의 경우 나머지가 1, 1, 0, 1 순서로 나오므로 11₁₀ = 1011₂다.

def to_binary(n):
    if n < 0:
        raise ValueError("use a separate signed representation")
    if n == 0:
        return "0"
    bits = []
    while n:
        n, remainder = divmod(n, 2)
        bits.append(str(remainder))
    return "".join(reversed(bits))

print(to_binary(11))
11 = 1×23 + 0×22 + 1×21 + 1×20

4. 10진 소수를 2진수로

소수 부분은 2를 반복해서 곱하고 매 단계의 정수 부분을 차례로 기록한다. 0.2₁₀ = 0.00110011…₂이며 0011이 무한히 반복된다. 따라서 0.00110011₂은 8자리 근사일 뿐 0.2와 정확히 같지 않다.

from fractions import Fraction

value = Fraction(1, 5)
bits = []
for _ in range(12):
    value *= 2
    bit = value.numerator // value.denominator
    bits.append(str(bit))
    value -= bit

print("0." + "".join(bits))

Fraction(1, 5)를 사용했기 때문에 각 단계는 유리수로 정확하다. 출력 0.001100110011에서 반복 패턴을 직접 확인할 수 있다.

5. 부동소수점 오차와 허용 오차

0.2처럼 기약분수로 줄였을 때 분모에 2 이외의 소인수가 있는 분수는 이진법의 유한한 비트로 정확히 표현할 수 없다. 현대 CPython의 float는 보통 IEEE 754 배정밀도 이진 부동소수점이므로 가장 가까운 표현 가능한 값을 저장한다. 따라서 반복 연산은 작은 표현·반올림 오차를 누적할 수 있다.

import math
from decimal import Decimal

print(0.1 + 0.2 == 0.3)
print(math.isclose(0.1 + 0.2, 0.3, rel_tol=1e-9, abs_tol=0.0))
print(Decimal("0.1") + Decimal("0.2"))
|a−b| ≤ max(rel_tol × max(|a|, |b|), abs_tol)

math.isclose의 허용 오차는 문제의 단위와 실패 비용에 맞춰 정한다. 십진 금액처럼 10진 규칙이 중요한 값은 문자열에서 만든 Decimal이 적합할 수 있다. 출력 자릿수를 줄이는 포맷은 표시를 바꿀 뿐 내부 오차를 제거하지 않는다.

for a in (14, -14):

7. 복소수와 복소평면

실수 범위에서는 x² ≥ 0이지만 복소수까지 확장하면 √−1을 허수 단위로 정의한다. 전기공학에서는 전류 기호 i와 혼동을 피하기 위해 j를 자주 쓰며, 파이썬은 허수 단위에 j를 사용한다.

import cmath

z = 3 + 4j
print(cmath.sqrt(-1))
print(z.conjugate())
print(abs(z))
z = a + bj  ·  z̄ = a − bj  ·  |z| = √(a²+b²)

복소평면의 가로축은 실수부, 세로축은 허수부다. 복소수는 교류 회로, 파동, 전자기장, 열·신호 해석, 푸리에 변환, 양자역학에서 크기와 위상을 함께 표현한다. 켤레복소수는 내적·에너지·스펙트럼 계산에서 빠뜨리기 쉬운 검증 지점이다.

8. 시프트와 2의 보수

왼쪽 시프트는 비트를 왼쪽으로, 오른쪽 시프트는 오른쪽으로 이동한다. 그러나 단순 시프트는 밀려난 비트를 되돌리지 않으므로 순환 회전과 다르다. 1의 보수는 모든 비트를 뒤집고, 2의 보수는 그 결과에 1을 더한다. 현대의 고정 폭 부호 정수는 일반적으로 2의 보수를 사용한다.

파이썬 정수는 임의 정밀도이므로 8비트처럼 자동으로 넘치거나 순환하지 않는다. 음수를 비트 패턴으로 직렬화하려면 명시적인 비트폭과 허용 범위를 정해야 한다.

def encode_twos(value, width=8):
    lower = -(1 << (width - 1))
    upper = 1 << (width - 1)
    if not lower <= value < upper:
        raise ValueError("value does not fit the signed width")
    return value & ((1 << width) - 1)

def decode_twos(bits, width=8):
    mask = (1 << width) - 1
    bits &= mask
    sign_bit = 1 << (width - 1)
    return bits - (1 << width) if bits & sign_bit else bits

encoded = encode_twos(-5)
print(f"{encoded:08b}")
print(decode_twos(encoded))
print(-5 >> 1)

8비트에서 −5는 11111011이고 다시 해석하면 −5다. 파이썬에서 음수 오른쪽 시프트는 부호를 유지하는 산술 시프트이므로 -5 >> 1은 −3이다.

9. 문맥을 사용하는 AI

초기의 문자 빈도 분석이나 n-gram은 가까운 문자·단어의 통계를 사용했다. 현대 언어 모델은 더 긴 문맥에서 다음 토큰의 조건부 확률을 계산하고, 사용자 피드백이나 검색 결과 같은 추가 신호를 결합할 수 있다. 즉 AI는 문맥에 맞는 후보를 확률적으로 순위화하지만, 이것이 참된 이해나 사실성을 자동으로 보장하지는 않는다.

지능형 CCTV는 탐지와 대응 우선순위 설정을 도울 수 있지만 범죄 예방을 보장하지 않는다. 모델 성능뿐 아니라 사람의 판단, 현장 절차, 편향과 사생활 보호를 함께 설계해야 한다.

10. CT·MRI와 계산적 재구성

CT는 X선 감쇠를 여러 각도에서 측정해 단면을 재구성한다. 이상적인 평행빔 CT는 라돈 변환과 역변환으로 설명할 수 있고, 실제 장비는 기하 구조·잡음·선량을 고려한 필터드 역투영 또는 반복 재구성 등을 사용한다.

MRI는 강한 자기장과 고주파 신호, 공간 부호화를 위한 경사자장을 사용하며 수집한 주파수 공간 데이터를 주로 푸리에 기반으로 재구성한다. CT와 MRI는 모두 계산이 중요하지만 측정 물리와 안전 조건이 다르다. 따라서 “영상”이라는 출력만 보고 같은 시스템으로 취급하면 안 된다.

11. 융합 시스템과 협업

AI 시스템은 수학·소프트웨어만으로 완성되지 않는다. 의료영상은 물리·의학·신호처리, 자율주행은 제어·센서·안전, 반도체 시스템은 회로·컴파일러·운영체제 지식이 함께 필요하다. 비행기는 양력을 만들어야 하지만 자동차는 떠오르지 않아야 하듯, 같은 알고리즘도 도메인의 물리적 제약에 따라 성공 조건이 달라진다.

도메인 문제 → 측정 모델 → 수학적 표현 → 구현 → 검증 → 전문가 피드백 → 개선

깊은 전문성은 모든 일을 혼자 하는 능력이 아니라 자신의 가정과 결과를 다른 분야 전문가가 검토할 수 있는 언어로 설명하는 능력과 함께 성장한다.

동료 코드 리뷰는 결과를 복사하거나 취향을 평가하는 활동이 아니다. 각자 독립적으로 구현한 뒤 상대 코드의 가정·정확성·경계 조건을 재현 가능한 근거로 분석한다.

This week examines how values are represented and interpreted inside a computer. The same mathematical value can behave differently depending on the object model, number system, and data type. The goal is not to trust a displayed number automatically, but to explain and verify its representation, tolerance, and boundary conditions.

1. Variables, Objects, and Memory

A variable name is not the memory address itself. In Python, a variable is a name bound to an object; the interpreter manages the object's actual storage. Assignment does not copy an object; it binds another name to the same object. A shallow copy creates a new outer container, while a deep copy recursively duplicates nested objects.

import copy

original = [[1, 2], [3, 4]]
alias = original
shallow = original.copy()
deep = copy.deepcopy(original)

original[0][0] = 99
print(alias[0][0], shallow[0][0], deep[0][0])

The output is 99 99 1. The alias and shallow copy share the first nested list; the deep copy does not. File cut-and-paste at the operating-system level and editor clipboard operations follow separate rules, so they should not be generalized into Python's object-assignment model.

2. Identifiers and Unique IDs

An identifier names a variable, function, or class in source code. A Python identifier cannot start with a digit or use a reserved keyword; readable snake_case is common. An arbitrary 64-character limit is not a general Python syntax rule.

ConceptPurposeExample
program identifierreadably names a value in codesensor_temperature
domain keydistinguishes an entity under business rulesstudent, order, or device ID
UUIDmakes collisions extremely unlikely in distributed systems128-bit UUID

Length alone does not guarantee uniqueness. Design the generation rule, scope, duplicate checks, and storage constraints together.

3. Converting Decimal Integers to Binary

Repeatedly divide a positive decimal integer by two and read the remainders from bottom to top. For 11, the remainders lead to 11₁₀ = 1011₂.

def to_binary(n):
    if n < 0:
        raise ValueError("use a separate signed representation")
    if n == 0:
        return "0"
    bits = []
    while n:
        n, remainder = divmod(n, 2)
        bits.append(str(remainder))
    return "".join(reversed(bits))

print(to_binary(11))
11 = 1×23 + 0×22 + 1×21 + 1×20

4. Converting Decimal Fractions to Binary

For a fractional part, repeatedly multiply by two and record the integer part at each step. 0.2₁₀ = 0.00110011…₂, with 0011 repeating forever. Therefore 0.00110011₂ is only an eight-bit approximation, not exactly 0.2.

from fractions import Fraction

value = Fraction(1, 5)
bits = []
for _ in range(12):
    value *= 2
    bit = value.numerator // value.denominator
    bits.append(str(bit))
    value -= bit

print("0." + "".join(bits))

Because Fraction(1, 5) is exact, each multiplication step remains rational. The output 0.001100110011 exposes the repeating pattern directly.

5. Floating-Point Error and Tolerance

A fraction such as 0.2 whose denominator in lowest terms contains a prime factor other than two cannot represent it exactly with a finite number of bits in binary. On modern systems, CPython's float is normally IEEE 754 binary64 and stores the nearest representable value. Repeated operations can therefore accumulate small representation and rounding errors.

import math
from decimal import Decimal

print(0.1 + 0.2 == 0.3)
print(math.isclose(0.1 + 0.2, 0.3, rel_tol=1e-9, abs_tol=0.0))
print(Decimal("0.1") + Decimal("0.2"))
|a−b| ≤ max(rel_tol × max(|a|, |b|), abs_tol)

Choose the math.isclose tolerances from the problem's units and failure cost. A Decimal constructed from strings can be appropriate when decimal rules matter, as in currency. Formatting fewer digits changes only the display; it does not remove the internal error.

6. Division Semantics

ExpressionResultMeaning
14 / 52.8true division

-14 // 5−3floors toward negative infinity
-14 % 51remainder with the divisor's sign

// floors toward negative infinity rather than truncating toward zero. For integers, a = (a // b) × b + (a % b) always holds.

for a in (14, -14):
    q, r = divmod(a, 5)
    print(a, q, r, q * 5 + r)

A floating-point remainder begins with approximate inputs, so decide whether the design needs a tolerance or integer scaling instead of exact equality.

7. Complex Numbers and the Complex Plane

Within the real numbers, x² ≥ 0. Extending the number system defines the imaginary unit as √−1. Electrical engineering often uses j to avoid confusing it with current i, and Python uses j for the imaginary unit.

import cmath

z = 3 + 4j
print(cmath.sqrt(-1))
print(z.conjugate())
print(abs(z))
z = a + bj  ·  z̄ = a − bj  ·  |z| = √(a²+b²)

The horizontal axis of the complex plane is the real part and the vertical axis is the imaginary part. Complex numbers represent magnitude and phase in AC circuits, waves, electromagnetism, thermal and signal analysis, Fourier transforms, and quantum mechanics. Conjugation is an easy-to-miss validation point in inner products, energies, and spectra.

8. Shifts and Two's Complement

A left shift moves bits left and a right shift moves them right. A simple shift discards ejected bits, so it differs from circular rotation. One's complement flips every bit; two's complement adds one to that result. Modern fixed-width signed integers generally use two's-complement representation.

Python integers have arbitrary precision, so they do not automatically overflow or wrap at eight bits. Serializing a negative integer as a bit pattern requires an explicit bit width and range.

def encode_twos(value, width=8):
    lower = -(1 << (width - 1))
    upper = 1 << (width - 1)
    if not lower <= value < upper:
        raise ValueError("value does not fit the signed width")
    return value & ((1 << width) - 1)

def decode_twos(bits, width=8):
    mask = (1 << width) - 1
    bits &= mask
    sign_bit = 1 << (width - 1)
    return bits - (1 << width) if bits & sign_bit else bits

encoded = encode_twos(-5)
print(f"{encoded:08b}")
print(decode_twos(encoded))
print(-5 >> 1)

At eight bits, −5 is 11111011 and decodes back to −5. Python right-shifts negative integers arithmetically, preserving the sign, so -5 >> 1 is −3.

9. Context-Aware AI

Early frequency analysis and n-gram models used statistics over nearby characters or words. Modern language models calculate conditional probabilities for the next token over longer contexts and can combine signals such as user feedback or retrieved information. An AI system therefore probabilistically ranks candidates that fit the context; this does not automatically guarantee genuine understanding or factual truth.

10. CT, MRI, and Computational Reconstruction

CT measures X-ray attenuation from multiple angles and reconstructs cross-sections. Ideal parallel-beam CT can be described with the Radon transform and its inverse; real systems account for geometry, noise, and dose through methods such as filtered back projection or iterative reconstruction.

MRI uses a strong magnetic field and radio-frequency signals, with gradient fields for spatial encoding, and commonly reconstructs acquired frequency-space data with Fourier-based methods. Computation matters to both modalities, but their measurement physics and safety constraints differ.

11. Interdisciplinary Systems and Collaboration

An AI system is not completed by mathematics and software alone. Medical imaging combines physics, medicine, and signal processing; autonomous driving combines control, sensing, and safety; semiconductor systems combine circuits, compilers, and operating systems. An aircraft must generate lift while a car must remain on the road: the same algorithm faces different success conditions under different physical constraints.

domain problem → measurement model → mathematics → implementation → validation → expert feedback → improvement

Deep expertise is not the ability to do everything alone. It grows together with the ability to explain assumptions and results in a form that specialists from other domains can examine.

12. Evidence-Based Peer Code Review

Peer code review is not answer copying or a matter of taste. Implement independently, then analyze assumptions, correctness, and boundary behavior with reproducible evidence.

Review principle. Go beyond “wrong.” Record the input, expected and actual results, cause hypothesis, improvement, and verification result as one chain. Even a plausible output needs theoretical, unit, and boundary checks.

Key Takeaways

  • A Python variable is a name bound to an object; assignment, shallow copy, and deep copy have different semantics.
  • Because 0.2 repeats in binary, floating-point comparisons require a tolerance chosen for the application.
  • Complex numbers and two's-complement patterns require representation rules before an output can be judged mathematically and operationally correct.
  • AI and engineering systems combine context with physical constraints and are validated through independent implementation and evidence-based review.
